## Prioridades de rotación

- **Medio frasco de pisto:** usar el sábado con el pollo.
- **Pollo congelado:** sacar un taco para el fin de semana y utilizarlo en 2 comidas.
- **Lomo adobado:** quedan **2 paquetes de 4 filetes**; usar 1–2 esta semana según tamaño/hambre.
- **Caldereta:** queda 1 tupper congelado; usar como comida.
- **Espinacas y guisantes:** rotar poco a poco, no gastarlos de golpe.
- **Atún con tomate y sardinetas:** seguir entrando progresivamente en el menú.
- **Pavo:** reservar principalmente para desayunos/post-CrossFit.
